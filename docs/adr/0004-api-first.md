# ADR-0004 — API-first contracts

**Status:** Proposed

OpenAPI 3.1 YAML in `api/openapi.yaml` is versioned before implementation. Story IDs in issues link operations and acceptance tests. Use ISO 8601 date/time formats, documented 400/401/403/404/409 behavior, and `application/problem+json` for errors. A draft contract is not evidence of implemented endpoints. Change contract and tests in the same PR as the feature.
